# PTA Timer

PTA Timer 是一个面向 PTA / 拼题 A（pintia.cn）的做题计时工具，支持浏览器本地插件和 Tampermonkey / Greasy Fork 油猴脚本两种使用方式。它可以在进入题目页后自动开始计时，在答题过程中显示悬浮计时器，并保存最近做题记录，帮助你更直观地复盘刷题效率。

## 项目链接

- GitHub：<https://github.com/Withnoidea/PATTimer>
- Greasy Fork / 油猴脚本：<https://greasyfork.org/zh-CN/scripts/579864-pta-timer>

## 适合谁使用

如果你经常在 PTA / 拼题 A 上刷 PAT、数据结构、程序设计基础、算法题，PTA Timer 可以帮你记录每道题的真实用时，避免只关注“做没做出来”，却忽略“做了多久”。

它特别适合：

- PAT / PTA 备考刷题
- 想统计单题耗时的同学
- 想模拟限时训练的同学
- 想复盘做题效率和卡题情况的同学
- 希望有轻量级本地工具，不想上传刷题数据的用户

## 功能概览

- 自动识别 PTA 题目页面并开始计时
- 题目页右上角显示悬浮计时器
- 支持暂停、继续、重置和倒计时
- 支持拖动悬浮计时器位置，或固定在页面上
- 支持打开内置面板查看历史记录和考试列表
- 提交结果为“答案正确”且满分时自动停止计时
- 最近记录显示题目名称、题目 ID、结束时间和用时
- 支持删除单条记录或清除全部数据
- 数据保存在浏览器本地，不上传到外部服务
- 提供 Greasy Fork 油猴脚本版本，安装更方便

## 安装方法

### 方法一：安装油猴脚本

适合只想快速使用的用户。

1. 安装 Tampermonkey / 篡改猴等用户脚本管理器。
2. 打开 PTA Timer 的 Greasy Fork 页面：
   <https://greasyfork.org/zh-CN/scripts/579864-pta-timer>
3. 点击安装脚本。
4. 打开 `https://pintia.cn/*` 页面即可使用。

### 方法二：加载本地浏览器插件

适合想本地调试、二次开发或使用扩展版本的用户。

#### Chrome

1. 下载或克隆本项目到本地。
2. 打开 `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目目录。
6. 打开 PTA 题目页开始使用。

#### Edge

1. 下载或克隆本项目到本地。
2. 打开 `edge://extensions/`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择本项目目录。
6. 打开 PTA 题目页开始使用。

## 使用说明

### 题目页悬浮计时器

进入 PTA 题目页面后，PTA Timer 会自动：

1. 提取当前题目 ID。
2. 读取页面上的题目名称。
3. 开始本题计时。
4. 在页面右上角显示悬浮计时器。

悬浮计时器支持以下操作：

| 操作 | 说明 |
| --- | --- |
| 暂停 / 继续 | 暂停后用时不再增长，再次点击继续计时 |
| 重置 | 清空当前题目用时并重新开始 |
| 倒计时 | 输入分钟数后开始倒计时 |
| 打开面板 | 查看历史记录、考试列表和设置 |
| 固定 | 固定后计时器不随页面滚动或拖动 |
| 拖动 | 未固定时可拖动到页面任意位置 |
| 关闭 | 隐藏当前页面上的悬浮计时器 |

### 提交全对自动停止

当 PTA 弹出“提交结果”窗口时，工具会检查提交结果弹窗内容：

- 状态包含“答案正确”
- 分数为满分，例如 `20 / 20`

满足条件后，当前题目计时会自动停止并写入最近记录。检测逻辑使用节流和局部 DOM 检查，避免提交后频繁扫描整页导致浏览器卡顿。

### 内置面板

点击悬浮计时器中的面板按钮，或通过用户脚本菜单打开 PTA Timer 面板，可以查看：

- 做题历史记录
- 当前题目用时
- 最近记录列表
- 考试列表 / 自定义考试相关入口
- 设置项和数据清理入口

最近记录支持：

- 显示题目名称
- 显示题目 ID 和结束时间
- 显示本次用时
- 删除单条记录

### 倒计时

在悬浮计时器或面板中都可以设置倒计时：

1. 点击倒计时按钮。
2. 输入分钟数。
3. 点击开始。

倒计时剩余时间较少时会变色提醒；时间结束后会触发浏览器通知或页面提示。

## 推荐搭配：PTA-COPY 题目复制助手

PTA-COPY 可以一键复制 PAT / PTA 题目为 Markdown 格式，并自动处理题面中的公式和干扰内容，适合整理错题本、题解仓库、复习笔记或博客文章。

- GitHub：<https://github.com/Withnoidea/PTA-COPY>
- Greasy Fork / 油猴脚本：<https://greasyfork.org/zh-CN/scripts/578991-pat-%E9%A2%98%E7%9B%AE%E5%A4%8D%E5%88%B6%E5%8A%A9%E6%89%8B>

PTA-COPY 主要功能：

- 一键复制 PAT / PTA 题目为 Markdown 格式
- 自动将 KaTeX 数学公式转换为 LaTeX 语法
- 清洗页面中的反爬干扰内容
- 生成更适合保存、发布和二次编辑的 `.md` 文档

## 数据说明

PTA Timer 使用浏览器本地存储保存数据，包括：

- 当前计时状态
- 暂停状态和暂停偏移
- 最近题目记录
- 倒计时状态
- 计时器固定状态
- 计时器拖动位置
- 考试模式相关状态

所有数据都保存在本地浏览器中，不会上传到外部服务。卸载扩展、清除浏览器扩展数据或点击“清除所有数据”后，历史记录会被删除。

## 常见问题

### 进入题目页后没有开始计时

请确认：

1. 当前页面域名是 `pintia.cn`。
2. 扩展或油猴脚本已启用。
3. 修改代码后已在扩展管理页点击“重新加载”，或在 Tampermonkey 中重新安装脚本。
4. 当前 URL 中能提取题目 ID，例如包含 `problemSetProblemId` 或 `/problems/`。

### 面板或图标显示异常

请尝试：

1. 重新安装最新版本脚本。
2. 刷新 PTA 页面。
3. 确认浏览器没有同时启用旧版本插件和新版本脚本。

### popup、面板和页面上的时间不一致

请重新加载扩展或脚本并刷新 PTA 页面。当前版本的计时状态由后台逻辑统一维护，popup、面板和悬浮计时器都会读取同一份状态。

### 提交后没有自动停止

自动停止依赖 PTA 提交结果弹窗中的文本：

- “提交结果”
- “答案正确”
- “分数 x / x”

如果 PTA 页面结构发生变化，需要更新提交结果检测逻辑。

### 提交后浏览器卡顿

当前版本已避免对整页 `innerText` 做高频扫描，改为只检查提交结果弹窗。如果仍然卡顿，请确认浏览器中没有加载旧版本扩展或脚本。

## 开发调试

修改本地插件代码后需要：

1. 打开浏览器扩展管理页。
2. 点击 PTA Timer 的“重新加载”。
3. 刷新 PTA 页面。
4. 重新测试题目计时和提交结果检测。

可以使用以下命令检查脚本语法：

```bash
node --check background.js
node --check content.js
node --check popup.js
```
