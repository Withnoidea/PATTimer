# PTA Timer

PTA Timer 是一个面向 PTA / 拼题 A（pintia.cn）的浏览器扩展，用于自动记录题目练习用时。进入题目页后自动开始计时，提交全对后自动停止，并在插件弹窗中保存最近记录。

## 功能概览

- 自动识别 PTA 题目页面并开始计时
- 题目页右上角显示悬浮计时器
- 支持暂停、继续、重置和倒计时
- 支持拖动悬浮计时器位置，或固定在页面上
- 提交结果为“答案正确”且满分时自动停止计时
- 点击浏览器扩展图标可查看当前题目、同步用时和最近记录
- 最近记录显示题目名称、题目 ID、结束时间和用时
- 支持删除单条记录或清除全部数据
- 数据保存在浏览器本地，不上传到外部服务

## 支持环境

- Chrome / Edge 等 Chromium 内核浏览器
- Manifest V3 扩展环境
- 仅匹配 `https://pintia.cn/*`

## 安装方法

### Chrome

1. 下载或克隆本项目到本地。
2. 打开 `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目目录。
6. 打开 PTA 题目页开始使用。

### Edge

1. 下载或克隆本项目到本地。
2. 打开 `edge://extensions/`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择本项目目录。
6. 打开 PTA 题目页开始使用。

## 使用说明

### 题目页悬浮计时器

进入 PTA 题目页面后，扩展会自动：

1. 提取当前题目 ID。
2. 读取页面上的题目名称。
3. 开始本题计时。
4. 在页面右上角显示悬浮计时器。

悬浮计时器支持以下操作：

| 操作 | 说明 |
| --- | --- |
| 暂停 / 继续 | 暂停后用时不再增长，再次点击继续计时 |
| 重置 | 清空当前题目用时并重新开始 |
| 倒计时 | 输入分钟数后开始倒计时 |
| 固定 | 固定后计时器不随页面滚动或拖动 |
| 拖动 | 未固定时可拖动到页面任意位置 |
| 关闭 | 隐藏当前页面上的悬浮计时器 |

### 提交全对自动停止

当 PTA 弹出“提交结果”窗口时，扩展会只检查提交结果弹窗内容：

- 状态包含“答案正确”
- 分数为满分，例如 `20 / 20`

满足条件后，当前题目计时自动停止并写入最近记录。检测逻辑使用节流和局部 DOM 检查，避免提交后频繁扫描整页导致浏览器卡顿。

### 插件弹窗

点击浏览器工具栏中的 PTA Timer 图标，可以查看：

- 当前题目名称
- 当前题目 ID
- 与页面悬浮计时器同步的题目用时
- 暂停 / 继续、重置、倒计时控制
- 最近记录列表

最近记录支持：

- 显示题目名称
- 显示题目 ID 和结束时间
- 显示本次用时
- 删除单条记录

### 倒计时

在悬浮计时器或插件弹窗中都可以设置倒计时：

1. 点击倒计时按钮。
2. 输入分钟数。
3. 点击开始。

倒计时剩余时间较少时会变色提醒；时间结束后会触发浏览器通知或页面提示。

## 数据说明

扩展使用 `chrome.storage.local` 保存数据，包括：

- 当前计时状态
- 暂停状态和暂停偏移
- 最近题目记录
- 倒计时状态
- 计时器固定状态
- 计时器拖动位置
- 考试模式相关状态

所有数据都保存在本地浏览器中。卸载扩展、清除浏览器扩展数据或点击“清除所有数据”后，历史记录会被删除。

## 常见问题

### 进入题目页后没有开始计时

请确认：

1. 当前页面域名是 `pintia.cn`。
2. 扩展已在浏览器扩展管理页启用。
3. 修改代码后已在扩展管理页点击“重新加载”。
4. 当前 URL 中能提取题目 ID，例如包含 `problemSetProblemId` 或 `/problems/`。

### popup 和页面上的时间不一致

请重新加载扩展并刷新 PTA 页面。当前版本的计时状态由 `background.js` 统一维护，popup 和悬浮计时器都会读取同一份后台状态。

### 提交后没有自动停止

自动停止依赖 PTA 提交结果弹窗中的文本：

- “提交结果”
- “答案正确”
- “分数 x / x”

如果 PTA 页面结构发生变化，需要更新 `content.js` 中的提交结果检测逻辑。

### 提交后浏览器卡顿

当前版本已避免对整页 `innerText` 做高频扫描，改为只检查提交结果弹窗。如果仍然卡顿，请确认浏览器中没有加载旧版本扩展。

## 开发调试

修改代码后需要：

1. 打开浏览器扩展管理页。
2. 点击 PTA Timer 的“重新加载”。
3. 刷新 PTA 页面。
4. 重新测试题目计时和提交结果检测。

可以使用以下命令检查脚本语法：

```bash
node --check background.js
node --check content.js
node --check popup.js
```
